# 🍁 메이플 투두 (Maple To-Do)

메이플스토리 캐릭터의 일일 숙제, 주간 콘텐츠, 보스 토벌 현황을 한곳에서 확인하고 관리할 수 있는 숙제 관리 서비스입니다. 캐릭터별 기본 숙제 조회와 즐겨찾기뿐 아니라, 사용자가 직접 등록하는 커스텀 숙제와 알림 기능도 지원합니다.

- **서비스 주소:** https://bhn0305.github.io/uiuxprogramming/
- **GitHub 저장소:** https://github.com/bhn0305/uiuxprogramming

## 1. 주요 사용자

- 메이플스토리의 일일 및 주간 숙제를 잊지 않고 관리하고 싶은 유저
- 여러 캐릭터의 숙제와 보스 클리어 현황을 한눈에 확인하고 싶은 유저
- 게임 기본 숙제 외에 자신만의 반복 일정을 추가하여 관리하고 싶은 유저
- 광고 없이 간결한 화면에서 숙제 완료 여부를 확인하고 싶은 유저

## 2. 서비스 목적

메이플스토리에서는 캐릭터별로 관리할 일일 퀘스트, 주간 콘텐츠, 주간 보스 항목이 많습니다. 본 서비스는 이러한 숙제 현황을 한 화면에서 빠르게 확인하고 완료 여부를 체크할 수 있도록 돕기 위해 제작되었습니다.

또한 커스텀 숙제 등록과 즐겨찾기, 필터 기능을 더해 반복되는 숙제 관리 과정을 더 간편하게 만들고자 했습니다.

## 3. 메뉴 구성

| 메뉴 | 주요 내용 |
| --- | --- |
| 캐릭터 등록 및 조회 | 캐릭터 닉네임을 입력하여 캐릭터 정보와 숙제 목록 조회 |
| 나만의 숙제 관리 | 일일 숙제, 주간 콘텐츠, 주간 보스 등 커스텀 숙제 등록 및 관리 |
| 서비스 소개 | 서비스의 목적과 주요 내용 안내 |
| 주요 기능 | 서비스에서 제공하는 기능 소개 |
| 이용 방법 | 메뉴별 기본 사용 방법 안내 |

## 4. 핵심 행동 및 주요 기능

### 4-1. 캐릭터 등록 및 조회

1. 캐릭터 닉네임 입력창에 조회할 닉네임을 입력합니다.
2. 입력 중 닉네임 형식을 실시간으로 검사합니다.
3. 조회 버튼을 누르면 캐릭터 정보를 불러옵니다.
4. 조회가 완료되면 프로필 이미지, 레벨, 직업과 일일·주간·보스 숙제 목록이 표시됩니다.

허용되지 않는 특수문자나 단독 자음·모음이 포함되거나 글자 수 조건에 맞지 않으면 안내 문구가 표시되며 조회가 제한됩니다. 존재하지 않는 캐릭터를 입력한 경우에도 오류 안내가 표시됩니다.

### 4-2. 숙제 완료 체크 및 필터

- 숙제 항목의 완료·미완료 상태가 표시되며, **등록된 항목만 보기** 체크박스로 전체 목록과 등록된 항목을 전환할 수 있습니다.

### 4-3. 캐릭터 즐겨찾기

- 캐릭터 프로필의 즐겨찾기 항목을 선택해 즐겨찾기에 추가하거나 해제할 수 있으며, 즐겨찾기 목록에서 캐릭터를 선택해 다시 조회할 수 있습니다.

### 4-4. 나만의 커스텀 숙제 관리

- 숙제 이름과 분류(일일 숙제·주간 콘텐츠·주간 보스)를 입력해 커스텀 숙제를 등록할 수 있습니다.
- **주간 보스**를 선택한 경우에만 보스 난이도 선택 항목이 활성화됩니다.
- 숙제 이름은 입력 중 글자 수와 특수문자 여부를 검사해 안내 및 오류 메시지를 표시합니다.
- 등록한 커스텀 숙제는 전체, 일반 숙제(일일/주간), 주간 보스 필터로 구분해 확인하거나 삭제할 수 있습니다.

### 4-5. 캐릭터 화면에서 커스텀 숙제 확인

- 즐겨찾기한 캐릭터 조회 화면에서 **커스텀 숙제 보기**를 선택하면 연결된 커스텀 숙제를 함께 확인하고 완료 여부를 전환할 수 있습니다.

### 4-6. 접속 시 숙제 알림

- 알림 설정이 켜진 커스텀 숙제가 있으면 서비스 접속 시 알림 창이 표시됩니다.
- **오늘 하루 이 알람 보지 않기**(24시간) 또는 **일주일간 보지 않기**(7일)를 선택해 일정 기간 알림을 숨길 수 있습니다.

### 4-7. 화면 테마 및 반응형 화면

- 테마 버튼으로 라이트 모드와 다크 모드를 전환할 수 있으며, 선택한 테마는 새로고침이나 재접속 후에도 유지됩니다.
- PC와 모바일 화면 크기에 맞춰 레이아웃과 메뉴가 배치됩니다.

### 4-8. 메뉴 이동 및 현재 위치 표시

- 주요 메뉴를 `nav`, `ul`, `li` 구조로 구성하고, 현재 활성화된 메뉴에만 `aria-current="page"`를 적용해 시각적으로 구분합니다.
- 메뉴 이동, 새로고침, 브라우저 뒤로 가기·앞으로 가기 시에도 현재 화면과 메뉴 선택 상태가 일치하도록 동기화됩니다.

### 4-9. 모바일 메뉴

- 좁은 화면에서는 메뉴 열기·닫기 버튼으로 사이드 메뉴를 여닫을 수 있으며, 상태에 따라 버튼 레이블과 `aria-expanded` 값이 갱신됩니다.
- 모바일 메뉴에서 항목을 선택하면 해당 화면으로 이동하면서 메뉴가 자동으로 닫힙니다.

## 5. 이벤트 테스트 결과 및 확인 순서

| 테스트 항목 | 확인 순서 | 기대 결과 |
| --- | --- | --- |
| 메뉴 구조 및 이동 | 상단 메뉴 확인 후 각 메뉴를 차례로 선택 | `nav > ul > li` 구조로 되어 있고 선택한 화면으로 이동함 |
| 현재 위치 및 히스토리 동기화 | 메뉴 이동 후 새로고침, 뒤로 가기, 앞으로 가기 실행 | 현재 화면에 해당하는 메뉴만 강조되고 `aria-current` 및 화면이 일치함 |
| 모바일 메뉴 동작 | 좁은 화면에서 메뉴 열기·닫기 및 항목 선택 | 메뉴가 열리고 닫히며 `aria-expanded`가 변경되고 이동 시 자동 닫힘 |
| 캐릭터 조회 및 유효성 검사 | 유효/무효/미등록 닉네임 입력 후 조회 | 형식 오류 안내 또는 프로필·레벨·직업·숙제 목록이 표시됨 |
| 숙제 필터 및 즐겨찾기 | 필터 체크박스 전환, 즐겨찾기 등록 후 목록에서 선택 | 조건에 맞게 숙제 목록이 바뀌고 즐겨찾기 캐릭터가 재조회됨 |
| 커스텀 숙제 관리 | 분류 선택, 숙제 등록, 필터 선택, 삭제 실행 | 보스 선택 시 난이도가 활성화되고 등록·필터링·삭제가 동작함 |
| 테마 및 반응형 화면 | 테마 전환 후 새로고침 및 창 크기 변경 | 테마 설정이 유지되고 PC·모바일 화면에서 레이아웃이 깨지지 않음 |
| 본문 바로가기 및 초점 표시 | `Tab`·`Shift+Tab`으로 이동 및 본문 바로가기 선택 | `#main-content`로 이동하고 현재 초점 요소에 `:focus-visible` 표시가 나타남 |
| 상태 문구 및 명도 대비 | 완료된 숙제와 오류·필수 안내 확인 | 색상 외에 `[완료]/[미완료]` 문구와 명확한 명도 대비로 구분됨 |
| 키보드 조작 및 버튼 이름 | 즐겨찾기 `Enter`/`Space` 조작, 삭제 버튼 이름 확인 | 키보드로 조회·토글이 가능하고 삭제 버튼에 숙제 이름이 안내됨 |
| 알림 모달 접근성 | 숙제 알림 모달 열림 상태에서 초점 및 `Escape` 키 확인 | 대화상자 속성이 적용되고 초점 이동 및 `Escape` 닫기가 동작함 |

### 기본 기능 확인 순서

1. 상단 메뉴 이동, 새로고침, 뒤로 가기·앞으로 가기로 화면과 현재 메뉴 표시가 일치하는지 확인합니다.
2. 모바일 화면 폭에서 메뉴 열기·닫기, 항목 선택 시 자동 닫힘, 레이아웃 겹침 여부를 확인합니다.
3. 캐릭터 닉네임 유효성 검사와 조회를 진행하고, 숙제 필터 및 즐겨찾기 등록·재조회를 확인합니다.
4. 나만의 숙제 관리에서 커스텀 숙제 등록, 분류 필터링, 삭제 및 접속 시 알림 모달 동작을 확인합니다.
5. 테마 전환 후 새로고침 유지 여부와 `Tab`·`Shift+Tab`·`Escape` 키보드 조작 및 초점 표시를 점검합니다.

### PC 및 모바일 확인

- **PC:** 상단 메뉴 전환, 히스토리 동기화, 캐릭터 조회, 커스텀 숙제 관리, 키보드 초점 이동이 정상 동작하는지 확인합니다.
- **모바일:** 사이드 메뉴 여닫기와 자동 닫힘, 화면 전환, 주요 버튼·입력 요소의 터치 및 가독성 상태를 확인합니다.

## 6. 이번 주 추가 및 수정 기능

- **색 대비 및 상태 정보 전달 개선:** 숙제 완료·미완료 상태에 `[완료] / [미완료]` 문구와 `aria-label`을 병기하고, 오류·필수 표시 및 완료 상태 색상의 명도 대비를 개선했습니다.
- **버튼·항목 이름 및 키보드 접근성 개선:** 즐겨찾기 항목을 키보드로 조작할 수 있는 버튼 형태로 구성하고, 삭제 버튼의 `aria-label`에 숙제 이름을 포함해 기능을 명확히 전달하도록 수정했습니다.
- **키보드 초점 표시 및 본문·모달 접근성 개선:** 본문 바로가기 링크와 `:focus-visible` 초점 표시를 추가하고, 즐겨찾기 체크박스의 키보드 접근성과 알림 모달의 대화상자 속성 및 초점 처리를 보완했습니다.
- **입력 안내 및 오류 메시지 접근성 개선:** 입력 필드와 도움말·오류 메시지를 `aria-describedby`로 연결하고 `role="alert"` 및 `aria-live="polite"`를 적용해 안내와 오류가 명확히 전달되도록 개선했습니다.

## 7. 서버 이용 안내

본 서비스는 무료 외부 서버(Backend)를 사용하여 배포되어 있습니다. 약 15분 동안 이용 기록이 없으면 서버가 대기 상태(Sleep Mode)로 전환되며, 이후 최초로 캐릭터 조회를 시도할 경우 서버 재구동에 약 30초~1분 정도가 소요될 수 있습니다.
