 🍁 메이플 투두 (Maple To-Do)

광고 없이 쾌적하게 메이플스토리 일일 숙제, 주간 콘텐츠, 보스 토벌 현황을 체크하고 관리할 수 있는 플래너 서비스입니다.

 1. 주요 사용자

* 광고 없는 깔끔한 화면에서 본인의 캐릭터 숙제 및 보스 클리어 현황을 간편하게 관리하고 싶은 메이플스토리 유저

 2. 서비스 목적

* 게임 내 번거로운 일일 퀘스트, 주간 콘텐츠, 보스 토벌 여부를 한눈에 조회하고 체크할 수 있는 직관적인 스케줄러 제공

 3. 핵심 행동

* 캐릭터 닉네임 입력 및 실시간 유효성 검사
* 조회 버튼 클릭
* 프로필 및 스케줄러 정보 확인
* 필터 조작을 통한 숙제 관리

 4. 완료 조건

* 캐릭터 프로필 이미지, 레벨, 직업 및 일일/주간/보스 스케줄러가 오류 없이 출력되고, 사용자가 필터 및 완료 상태를 최종 확인한 시점

 5. 구현한 이벤트 및 기능

* 다크모드: 상단 테마 버튼을 누르면 다크모드와 라이트모드가 전환되며, localStorage에 저장되어 새로고침해도 설정이 유지됨
* 메뉴 탭 전환: 상단 메뉴를 누르면 페이지 이동 없이 해당 화면만 바로 보여주는 SPA 방식 적용
* 닉네임 입력 감지: 검색창에 닉네임 입력 시 실시간으로 상태 안내 문구 및 유효성 검사 결과 변경
* 캐릭터 조회 및 API 연동: 닉네임 검색 시 넥슨 API를 호출하여 프로필과 숙제 데이터를 가져옴
* 숙제 필터링: 등록된 항목만 보기 체크박스를 켜고 끌 때마다 숙제 목록이 실시간으로 재렌더링됨
* 즐겨찾기 기능 : 조회된 캐릭터의 아바타 우측 상단 별표(⭐)를 눌러 로컬스토리지에 저장하고, 하단에 생성되는 칩을 통해 자주 찾는 캐릭터를 원클릭으로 재조회할 수 있음

 6. 화면 변화 및 인터랙션 시나리오

* 탭 변경 시 화면 전환: SPA 방식으로 화면 깜빡임 없이 필요한 섹션만 노출됨
* 다크모드: 어두운 배경과 카드 스타일로 변경되며, 새로고침 시 깜빡임 방지 처리가 적용됨
* 조회 성공 시 카드 출력: 검색 성공 시 숨겨져 있던 캐릭터 프로필 카드와 숙제 목록이 나타남
* 완료된 숙제 색상 변경: 이미 완료한 숙제나 보스는 연두색 태그(`.completed`)로 하이라이트 처리됨
* 보스 난이도 배지: 이지, 노멀, 하드 등 난이도별 색상 배지가 적용됨
* 유효성 검사 예외 처리: 특수문자나 단독 자음/모음, 글자수 초과(한글 8자, 영문/숫자 16자) 입력 시 안내 문구 출력 및 조회가 차단됨

 7. 테스트 결과

**테스트용 닉네임 안내**
- **정상 조회 (실존 닉네임)**: `렌데숭`, `유이요이` (프로필 및 숙제 데이터 정상 출력 확인용)
- **에러 처리 (존재하지 않는 닉네임)**: `메이플 투두` (에러 메시지 출력 및 카드 비활성화 확인용)

* 정상 조회: 유효한 닉네임 검색 시 프로필 이미지, 레벨, 일퀘 및 주간보스 데이터가 정상적으로 불러와짐
* 에러 처리: 존재하지 않는 닉네임 검색 시 카드가 노출되지 않고 에러 문구가 정상적으로 뜸
* 유효성 검사 테스트: 특수문자 및 단독 자모음, 글자수 제한 조건 위배 시 안내 문구 출력 및 차단 확인
* 필터 동작: 체크박스를 켜면 인게임에서 등록한 숙제만 나오고, 끄면 전체 숙제가 정상적으로 출력됨
* 즐겨찾기 테스트: 별표 클릭 시 하단에 칩이 생성되고, 해당 칩을 누르면 캐릭터가 정상적으로 재조회됨
* 반응형: 모바일 화면으로 줄여도 UI가 깨지지 않고 깔끔하게 세로로 정렬됨
