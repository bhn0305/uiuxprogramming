# 🍁 메이플 투두 (Maple To-Do)

메이플스토리 캐릭터의 일일 숙제, 주간 콘텐츠, 보스 토벌 현황을 한곳에서 확인하고 관리할 수 있는 숙제 관리 서비스입니다. 캐릭터별 기본 숙제뿐 아니라 사용자가 직접 등록한 커스텀 숙제도 관리할 수 있습니다.

- **서비스 주소:** https://bhn0305.github.io/uiuxprogramming/
- **GitHub 저장소:** https://github.com/bhn0305/uiuxprogramming

## 1. 주요 사용자

- 메이플스토리의 일일 및 주간 숙제를 잊지 않고 관리하고 싶은 유저
- 여러 캐릭터의 숙제와 보스 클리어 현황을 한눈에 확인하고 싶은 유저
- 게임 기본 숙제 외에 자신만의 반복 일정을 추가하여 관리하고 싶은 유저
- 광고 없이 간결한 화면에서 숙제 완료 여부를 확인하고 싶은 유저

## 2. 서비스 목적

메이플스토리에서는 캐릭터별로 수행해야 하는 일일 숙제와 주간 콘텐츠, 보스 토벌 등 관리할 항목이 많습니다. 메이플 투두는 이러한 항목을 한 화면에서 확인하고 완료 여부를 직접 체크할 수 있도록 돕는 것을 목적으로 합니다.

또한 커스텀 숙제 등록 기능을 제공하여 기본 목록에 없는 개인 일정을 추가할 수 있도록 하고, 즐겨찾기와 필터 기능을 통해 반복적인 숙제 관리 과정을 간편하게 만드는 것을 목표로 합니다.

## 3. 메뉴 구성

| 메뉴 | 주요 내용 |
| --- | --- |
| 캐릭터 등록 및 조회 | 캐릭터 닉네임을 입력하여 캐릭터 정보와 숙제 목록 조회 |
| 나만의 숙제 관리 | 일일 숙제, 주간 숙제, 주간 보스 등 커스텀 숙제 등록 및 관리 |
| 서비스 소개 | 서비스의 목적과 주요 내용 안내 |
| 주요 기능 | 서비스에서 제공하는 기능 소개 |
| 이용 방법 | 메뉴별 기본 사용 방법 안내 |

## 4. 핵심 행동 및 주요 기능

### 4-1. 캐릭터 등록 및 조회

1. 캐릭터 닉네임 입력창에 조회할 닉네임을 입력합니다.
2. 입력 중 닉네임의 형식이 실시간으로 검사됩니다.
3. 조회 버튼을 누르면 캐릭터 정보를 불러옵니다.
4. 조회에 성공하면 프로필 이미지, 레벨, 직업과 일일·주간·보스 숙제 목록이 표시됩니다.

닉네임에 허용되지 않는 특수문자나 단독 자음·모음이 포함되거나 입력 길이가 조건에 맞지 않으면 안내 문구가 표시되며 조회가 제한됩니다. 존재하지 않는 캐릭터를 입력한 경우에도 오류 안내가 표시됩니다.

### 4-2. 숙제 완료 체크 및 필터

- 숙제 항목을 클릭하면 완료 상태와 미완료 상태가 전환됩니다.
- 완료된 항목은 시각적으로 구분되어 현재 진행 상황을 쉽게 확인할 수 있습니다.
- **등록된 항목만 보기** 체크박스를 이용해 등록된 숙제만 보거나 전체 숙제 목록을 확인할 수 있습니다.

### 4-3. 캐릭터 즐겨찾기

- 캐릭터 프로필의 별표 버튼을 누르면 해당 캐릭터를 즐겨찾기에 등록할 수 있습니다.
- 즐겨찾기한 캐릭터는 별도의 목록으로 표시됩니다.
- 즐겨찾기 목록의 캐릭터를 선택하면 해당 캐릭터를 다시 조회할 수 있습니다.

### 4-4. 나만의 커스텀 숙제 관리

- 사용자가 숙제 이름과 분류를 입력하여 자신만의 숙제를 등록할 수 있습니다.
- 숙제 분류는 일반 숙제(일일·주간)와 주간 보스로 구분됩니다.
- 주간 보스를 선택한 경우에만 난이도 선택 항목을 사용할 수 있습니다.
- 숙제 이름은 입력 중 글자 수와 입력 조건이 검사되며, 조건에 맞지 않으면 오류 문구와 시각적 피드백이 표시됩니다.
- 등록한 커스텀 숙제는 목록에서 확인하고 삭제할 수 있습니다.
- 목록 필터를 이용해 전체 숙제, 일반 숙제, 주간 보스를 구분하여 볼 수 있습니다.

### 4-5. 캐릭터 화면에서 커스텀 숙제 확인

- 캐릭터 조회 화면에서 **커스텀 숙제 보기**를 선택하면 즐겨찾기한 캐릭터에 연결된 커스텀 숙제를 함께 확인할 수 있습니다.
- 표시된 커스텀 숙제도 클릭하여 완료 여부를 변경할 수 있습니다.

### 4-6. 접속 시 숙제 알림

- 알림을 설정한 커스텀 숙제가 있으면 서비스 접속 시 알림 창이 표시됩니다.
- **오늘 하루 보지 않기**를 선택하면 24시간 동안 알림이 표시되지 않습니다.
- **일주일간 보지 않기**를 선택하면 7일 동안 알림이 표시되지 않습니다.

### 4-7. 화면 테마 및 반응형 화면

- 테마 버튼으로 라이트 모드와 다크 모드를 전환할 수 있습니다.
- 선택한 테마는 다시 접속하거나 새로고침해도 유지됩니다.
- PC와 모바일 화면 크기에 맞춰 콘텐츠와 메뉴가 배치되도록 구성했습니다.

### 4-8. 메뉴 이동 및 현재 위치 표시

- 주요 메뉴를 `nav`, `ul`, `li` 구조로 구성하여 서비스의 각 화면으로 이동할 수 있도록 구현했습니다.
- 메뉴를 선택하면 해당 메뉴에 연결된 화면으로 이동합니다.
- 현재 사용자가 위치한 메뉴는 다른 메뉴와 시각적으로 구분되도록 표시됩니다.
- 현재 메뉴에는 `aria-current` 속성을 적용하고, 다른 메뉴에서는 해당 속성이 제거되도록 구현했습니다.
- 메뉴 이동뿐 아니라 페이지 새로고침 및 브라우저 뒤로 가기·앞으로 가기 이후에도 실제 화면과 현재 메뉴 표시가 일치하도록 개선했습니다.

### 4-9. 모바일 메뉴

- 모바일과 같이 화면 폭이 좁은 환경에서는 메뉴 열기·닫기 버튼을 통해 주요 메뉴를 펼치거나 접을 수 있습니다.
- 메뉴의 실제 표시 상태에 따라 버튼 문구와 `aria-expanded` 값이 함께 변경됩니다.
- 메뉴에서 목적지를 선택하면 해당 화면으로 이동하고 펼쳐진 메뉴는 자동으로 닫힙니다.
- PC에서는 주요 메뉴가 정상적으로 표시되며, 모바일에서는 메뉴 버튼과 콘텐츠가 겹치지 않도록 구성했습니다.

### 기본 기능 확인 순서

1. 서비스에 접속한 뒤 상단 메뉴를 선택하여 각 화면으로 이동합니다.
2. 특정 메뉴를 선택한 상태에서 새로고침하여 현재 위치 표시가 유지되는지 확인합니다.
3. 여러 메뉴를 이동한 뒤 브라우저 뒤로 가기와 앞으로 가기를 실행하여 위치 표시가 실제 화면과 일치하는지 확인합니다.
4. 모바일 크기로 브라우저 화면을 변경하고 메뉴 열기·닫기 버튼을 눌러 메뉴 상태가 정상적으로 변경되는지 확인합니다.
5. 모바일 메뉴에서 다른 목적지를 선택하여 화면 이동 후 메뉴가 자동으로 닫히는지 확인합니다.
6. 캐릭터 등록 및 조회 메뉴에서 캐릭터 닉네임을 입력하고 조회합니다.
7. 캐릭터 숙제 항목을 클릭하여 완료 상태를 변경하고 필터 기능을 확인합니다.
8. 캐릭터 프로필의 별표를 눌러 즐겨찾기에 등록하고 다시 조회합니다.
9. 나만의 숙제 관리 메뉴에서 커스텀 숙제를 등록하고 필터 및 삭제 기능을 확인합니다.
10. 테마를 변경하고 새로고침하여 설정이 유지되는지 확인합니다.

### PC 및 모바일 확인

- **PC:** 메뉴 이동, 현재 위치 표시, 새로고침, 브라우저 뒤로 가기·앞으로 가기, 캐릭터 조회 및 숙제 관리 기능을 확인합니다.
- **모바일:** 메뉴 열기·닫기, 메뉴 선택 후 자동 닫힘, 화면 전환, 캐릭터 조회 및 숙제 관리 기능을 확인합니다. 화면 요소가 겹치거나 잘리지 않는지도 확인합니다.

## 6. 이번 주 추가 및 수정 기능
- **메뉴 구조 개선:** 주요 메뉴를 `nav`와 `ul`, `li` 구조로 수정하여 서비스에 맞는 메뉴 구성을 적용했습니다.
- **현재 위치 표시 기능 개선:** 사용자가 현재 위치한 메뉴가 다른 메뉴와 시각적으로 구분되도록 수정했습니다.
- **페이지 이동 상태 동기화:** 메뉴 이동뿐 아니라 새로고침 및 브라우저 뒤로 가기·앞으로 가기 이후에도 현재 화면과 메뉴의 선택 표시가 일치하도록 개선했습니다.
- **접근성 속성 적용:** 현재 선택된 메뉴에 `aria-current`를 적용하고, 다른 메뉴에서는 해당 속성이 제거되도록 수정했습니다.
- **모바일 메뉴 추가:** 좁은 화면에서 메뉴 열기·닫기 버튼을 통해 주요 메뉴를 펼치거나 접을 수 있도록 구현했습니다.
- **모바일 메뉴 상태 개선:** 메뉴의 열림 상태에 따라 버튼 문구와 `aria-expanded` 값이 함께 변경되도록 적용했습니다.
- **모바일 메뉴 이동 개선:** 메뉴에서 목적지를 선택하면 해당 화면으로 이동하고, 펼쳐진 메뉴가 자동으로 닫히도록 수정했습니다.
- **반응형 화면 개선:** PC에서는 주요 메뉴가 정상적으로 표시되고, 모바일에서는 메뉴 버튼과 콘텐츠가 겹치지 않도록 화면 구성을 개선했습니다.

## 7. 업데이트 내역

## 8. 서버 이용 안내

본 서비스는 무료 외부 서버(Backend)를 사용하여 배포되어 있습니다.

약 15분 동안 이용 기록이 없으면 서버가 일시적으로 대기 상태(Sleep Mode)로 전환됩니다.

이 상태에서 최초로 캐릭터 조회를 시도할 경우, 서버가 다시 구동되는 데 약 30초~1분 정도의 시간이 소요될 수 있습니다. 잠시 기다려 주시면 서버가 정상적으로 구동된 후 캐릭터 조회를 이용하실 수 있습니다.
