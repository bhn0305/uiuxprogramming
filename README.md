메이플 투두

구현한 이벤트
- 다크모드 : 상단 테마 버튼 누르면 다크모드/라이트모드로 바뀜. localStorage 저장해둬서 새로고침해도 설정 유지됨.
- 메뉴 탭 전환 : 상단 메뉴 누르면 페이지 이동 없이 해당 화면만 바로 보여줌.
- 닉네임 입력 감지 : 검색창에 닉네임 입력할 때 실시간으로 상태 안내 문구 변경됨.
- 캐릭터 조회 및 API 연동 : 닉네임 검색하면 넥슨 API 불러와서 프로필이랑 숙제 데이터 가져옴.
- 숙제 필터링 : 등록된 항목만 보기 체크박스 켜고 끌 때마다 숙제 목록 재렌더링.

화면 변화

- 탭 변경시 화면 전환 : SPA 방식이라 화면 깜빡임 없이 필요한 섹션만 딱 보임.
- 다크모드 : 어두운 배경과 카드 스타일로 싹 변경되고 새로고침 시 깜빡임 방지 처리함.
- 조회 성공 시 카드 출력 : 검색 성공하면 숨겨져 있던 캐릭터 프로필 카드랑 숙제 목록이 나타남.
- 완료된 숙제 색상 변경 : 이미 끝낸 숙제나 보스는 연두색 태그로 하이라이트 쳐줌.
- 보스 난이도 배지 : 이지, 노멀, 하드 등 난이도별로 색상 배지 달아줌.

테스트 결과
- 정상 조회 : 닉네임 검색하면 프로필 이미지, 레벨, 일퀘/주간보스 데이터 잘 불러와짐. (렌데숭)
- 에러 처리 : 없는 닉네임 치면 카드 안 나오고 에러 문구 뜸. (메이플투두)
- 필터 동작 : 체크박스 켜면 인게임에서 등록한 숙제만 나오고 끄면 전체 숙제 다 잘 나옴.
- 반응형 : 모바일 화면으로 줄여도 UI 안 깨지고 깔끔하게 세로 정렬됨.
